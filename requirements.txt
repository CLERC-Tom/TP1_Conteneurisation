Outils à installer (aucun paquet pip) : Docker, kubectl, kind.

Mac
  brew install --cask docker
  brew install kubectl kind

Windows (PowerShell)
  winget install -e --id Docker.DockerDesktop
  winget install -e --id Kubernetes.kubectl
  winget install -e --id Kubernetes.kind

Linux
  curl -fsSL https://get.docker.com | sh
  sudo usermod -aG docker $USER
  ARCH=$(uname -m | sed 's/x86_64/amd64/;s/aarch64/arm64/')
  curl -Lo kubectl "https://dl.k8s.io/release/$(curl -Ls https://dl.k8s.io/release/stable.txt)/bin/linux/$ARCH/kubectl"
  curl -Lo kind "https://kind.sigs.k8s.io/dl/latest/kind-linux-$ARCH"
  chmod +x kubectl kind && sudo mv kubectl kind /usr/local/bin/

Vérification (Docker Desktop lancé, 4 Go de RAM libres)
  docker version
  kubectl version --client
  kind version
